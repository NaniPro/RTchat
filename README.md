# RTchat

**Application web de discussion en temps réel**

RTchat est une application web de messagerie conçue pour permettre aux utilisateurs de communiquer à travers une interface simple et accessible. Le projet repose sur JavaScript et Firebase.

**Démo en ligne :** https://rtchat-app.web.app

---

## Fonctionnalités

- Création de compte et authentification des utilisateurs.
- Interface de connexion.
- Communication en temps réel.
- Interface web dédiée à la messagerie.
- Intégration avec les services Firebase.

## Technologies utilisées

- **HTML5** — Structure des pages.
- **CSS3** — Mise en page et interface utilisateur.
- **JavaScript** — Logique applicative et interactions.
- **Firebase** — Services backend et hébergement.

## Hébergement

L'application est déployée avec Firebase Hosting.

Démo : https://rtchat-app.web.app
